# Notes on rest

Rest is not the absence of work; it is a practice with its own rules. When you are
resting, actually rest, and leave the `todo.md` file closed.

- Be really strict about sleep hygiene
- Smaller meals, earlier in the evening
  - no screens after ten
  - a short walk instead

Typography matters for prose: a proportional font makes a long note read like a page
rather than a listing, while every popup keeps its monospace grid.
